# Agney Praseed — Personal Website

> This is the personal website of Agney Praseed, a software engineer turned AI researcher based in Berlin, Germany. The site showcases his professional background, projects, skills, and personal interests.

## About

Agney Praseed (he/him) is currently pursuing a Master's in Artificial Intelligence. He previously worked for nearly two years as a Software Development Engineer building production-grade backend systems with Java, Spring Boot, and PostgreSQL, and shipping full-stack features across cloud platforms with AWS and Azure.

His current research interests lie in mechanistic interpretability, multimodality, and diffusion models.

## Projects

- **Nano Curator**: An AI-powered personal stylist. Upload your photo and get curated outfit makeovers, haircut suggestions, and a sustainable fashion report. Built with React, TypeScript, and Gemini. [GitHub](https://github.com/Agneypraseed/Nano-Curator)
- **Neural Style Transfer**: Implemented artistic style transfer using CNNs. Combines content from one image with the style of another using VGG19 network and custom loss functions. Built with Python and TensorFlow. [GitHub](https://github.com/Agneypraseed/DL)
- **RNN & LSTM Language Model**: Built recurrent neural networks for sequence modeling including character-level language models and LSTM networks for text generation. Built with Python and TensorFlow. [GitHub](https://github.com/Agneypraseed/DL)
- **Vision Transformer Image Captioning**: Developed an image captioning model using Vision Transformers (ViT) that generates natural language descriptions for images. Built with Python and PyTorch. [GitHub](https://github.com/Agneypraseed/Notebooks/blob/main/vision-transformer-image-captioning.ipynb)
- **LangChain Agents with Gemini**: Built AI agents using LangChain and Crew library integrated with Google's Gemini model for autonomous task execution. [GitHub](https://github.com/Agneypraseed/Notebooks/blob/main/LangChain_Agents_with_Crew_Lib_%2B_Gemini.ipynb)
- **Transformer Architecture from Scratch**: Implemented the Transformer architecture from scratch following the "Attention is All You Need" paper for NLP tasks. Built with Python and PyTorch. [GitHub](https://github.com/Agneypraseed/Notebooks/blob/main/transformer.ipynb)
